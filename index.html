Features

Bermuda Reborn has been specially optimized for Android to bring the best possible gaming experience of this classic title to modern devices.

📱

Context-Sensitive Touch Overlay

Gameplay, menus, video, and inventory each get their own button set. Buttons appear and disappear automatically depending on what you're doing.

🎮

Game Controller Support

Detects gamepads on launch with opt-in prompt. All buttons fully remappable via the controller settings dialog. D-Pad navigates menus.

🔧

Customizable Layout

Drag buttons to reposition, long-press to resize, lock to save. Import/export presets. Every button is editable — size, shape, action, icon.

💼

Custom Savegame System

10 save slots with unique names, savestate preview, and date tracking. Quicksave & Quickload with a single tap, separate from manual slots.

🎵

MIDI Music Playback

TinySoundFont-powered MIDI playback for the original Bermuda Syndrome soundtrack. YUV video playback for cutscenes via the original codec.

🔫

Native Cheats

God Mode, Infinite Ammo, All Weapons. Toggle cheats via the touch overlay settings gear.

How to Install

You need to own a copy of Bermuda Syndrome (1995). Bermuda Reborn does not include any game files.

1

Copy your game data to your device

Copy your complete BERMUDA folder — containing all original game files — to a location on your Android device, e.g. /sdcard/games/bermuda.

2

Launch Bermuda Reborn and pick the folder

On first launch, the app opens a folder picker. Select the folder containing your game data. The app validates the required files and imports them.

3

Confirm and play

If all required files are found, you're in. The game starts directly. If a gamepad is connected, you'll be asked if you want to use it.

4

Expected folder layout

YourFolder/ should contain BERMUDA.SPR, BERMUDA.WGP, plus the SCN/ and MIDI/ subdirectories with all their original files.

Features

  • Full native engine via SDL2 — reverse-engineered Bermuda Syndrome recreation by Gregory Montour, running at native speed.
  • Asset-free build (~18 MB APK) — game data loaded via Android Storage Access Framework (SAF) folder picker.
  • Context-sensitive touch overlay — separate button sets for gameplay, menus, video, inventory, and combat modes (Gun/Sword armed states).
  • Game controller support — automatic gamepad detection with opt-in prompt and full button remapping.
  • Fully customizable overlay — drag to reposition, long-press to resize, lock to save. Import/export presets via JSON.
  • MIDI music playback via TinySoundFont for the original Bermuda Syndrome soundtrack.
  • Native cheats: God Mode, Infinite Ammo, All Weapons — toggleable via the overlay settings.
  • Custom savegame system — 10 save slots with unique names, savestate preview, and date tracking.
  • Quicksave & Quickload — instant save/load with a single tap, separate from manual slots.
  • 16:9 widescreen gameplay with 4:3 menus, inventory, and video presentation.
  • YUV video playback for original Bermuda Syndrome cutscenes.

Known Issues

  • Unlimited Ammo Cheat: When enabled, HUD displays incorrect ammo count and reload animation loops. Workaround: use DPAD-Up to break out of reload. Normal gameplay is unaffected.
